# modulo3_exercicio
## Como executar 
1- Abra o terminal Linux (WSL/Ubuntu).

2- Vá até a pasta do arquivo.

3- Dê permissão de execução: chmod 744 executar.sh

4- Execute o arquivo: ./executar.sh

## Explicação do Código Python
Este repositório contém o meu primeiro projeto prático: uma calculadora interativa desenvolvida em Python. 
O objetivo principal foi aplicar conceitos de lógica de programação, estruturas condicionais e tratamento de dados de entrada.
